\# Study Task Tracker



\## Concept Brief



The Study Task Tracker is a beginner-friendly web application designed to help students organize their academic responsibilities. Users will be able to add assignments, include course names and due dates, mark tasks as completed, and remove tasks they no longer need. The application uses Python and Flask for its core functionality, HTML and CSS for the interface, and SQLite for storing task information. The project provides practical experience with web development, databases, automated testing, version control, and AI-assisted programming.



\## Declared Stack



\- Language: Python

\- Web framework: Flask

\- Front end: HTML and CSS

\- Database: SQLite

\- Package manager: pip

\- Test runner: pytest

\- Version control: Git and GitHub

\- AI coding tool: ChatGPT/Codex



\## Current Milestone



This milestone contains a working Flask home page and an automated test. Task creation, completion, deletion, and database storage will be added in later milestones.
